### 1.1 SQL Data Definition Language (DDL) Script
```text-kondratiev-waves-data-processed-sqlite-sqlite-deep-dive-2
-- Core Kondratiev Cycle Table
CREATE TABLE IF NOT EXISTS kw_cycles (
    wave_id TEXT PRIMARY KEY,
    wave_number INTEGER NOT NULL,
    start_year INTEGER NOT NULL,
    end_year INTEGER NOT NULL,
    peak_year INTEGER,
    trough_year INTEGER,
    dominant_epicenter TEXT NOT NULL,
    gpt_engine TEXT NOT NULL
);

-- Macroeconomic Indicator Time Series Table
CREATE TABLE IF NOT EXISTS kw_indicators (
    indicator_id INTEGER PRIMARY KEY AUTOINCREMENT,
    wave_id TEXT NOT NULL,
    year INTEGER NOT NULL,
    country_code TEXT NOT NULL,
    indicator_code TEXT NOT NULL,
    value_raw REAL,
    value_clean REAL,
    FOREIGN KEY (wave_id) REFERENCES kw_cycles(wave_id)
);

-- Indexing for Fast Time-Series Queries
CREATE INDEX IF NOT EXISTS idx_indicators_year_code ON kw_indicators(year, indicator_code);
CREATE INDEX IF NOT EXISTS idx_indicators_wave ON kw_indicators(wave_id);
```end-kondratiev-waves-data-processed-sqlite-sqlite-deep-dive-2

## 3. Comparative Perspectives, Critiques & Counter-Theories (SQLite) (SQLite Deep Dive)

Database design for long-wave research must explicitly account for statistical critiques:

1. **Slutsky-Yule Filter Artifact Hiding (Solomou, 1987)**: Storing pre-filtered data in relational tables without raw counterparts can mask artificial periodicities generated by detrending filters. The SQLite schema explicitly mandates separate columns for `value_raw` and `value_clean`.
2. **Stochastic Trend Non-Stationarity (Nelson & Plosser, 1982)**: Macroeconomic time series stored in SQL possess unit roots $I(1)$:
$$Y_{t, \text{kondratiev\_wave}} = \mu_{\text{kondratiev\_wave}} + Y_{t-1, \text{kondratiev\_wave}} + \epsilon_{t, \text{kondratiev\_wave}}$$
   Analytical SQL queries should not calculate simple moving averages without accounting for non-stationarity.
3. **Neoclassical Growth Rejection (Solow, 1956)**: Neoclassical growth models treat productivity as continuous exogenous growth $A(t) = A_0 e^{gt}$, making discrete cycle tables theoretically redundant from a Solow perspective.

### Relational Database Schema and Query Optimization

The SQLite relational storage engine provides high-performance, indexed querying across multi-century cliometric records, cross-country output panels, and technological innovation inventories. Relational schemas enforce foreign-key consistency and transactional integrity.

| Database Table Name | Primary Key Structure | Foreign Key Dependencies | Indexing Strategy |
| :--- | :--- | :--- | :--- |
| `waves_master` | `wave_id` (INTEGER) | None (Root Entity) | Clustered on `wave_id` |
| `annual_series` | `(series_id, year)` | `series_id` -> `series_metadata` | Composite B-Tree `(year, series_id)` |
| `techno_innovations`| `innovation_id` (INTEGER)| `wave_id` -> `waves_master` | Secondary B-Tree on `diffusion_year` |
| `spectral_estimates`| `estimate_id` (INTEGER) | `wave_id` -> `waves_master` | Covering Index on `frequency_bin` |

High-throughput analytical queries utilize optimized relational aggregations to compute rolling volatility metrics:

```sql
SELECT year, 
       AVG(filtered_amplitude) OVER (ORDER BY year ROWS BETWEEN 24 PRECEDING AND 24 FOLLOWING) AS rolling_wave_mean,
       VARIANCE(filtered_amplitude) OVER (ORDER BY year ROWS BETWEEN 24 PRECEDING AND 24 FOLLOWING) AS rolling_wave_var
FROM annual_series
WHERE series_id = 'US_UK_MERGED_OUTPUT';
```
